# ANIMANIA! : ANDROID PORT — Native game foundation

This folder is the beginning of the **native Android game**, built with Haxe, OpenFL and HaxeFlixel. It is not a WebView or an HTML game.

## Current prototype
- Native HaxeFlixel game state with a black background.
- OpenFL live FPS counter in the upper-left corner.
- Android package: `com.johan.animaniaandroidport`.
- Landscape game window, 1280×720 logical resolution.

## Build prerequisites
Install Haxe, HaxeFlixel, OpenFL, Lime, and the Android SDK/NDK. From this folder, install the Haxe libraries and build with Lime for Android.

This is only the native engine foundation. It does not yet load Funkin/V-Slice mods or their assets; compatible asset readers and gameplay systems must be implemented after the source assets are reviewed.
